### 評估規則

1. **一致性評估**
   - 比較 LLM 的投票結果與人類評審的平均投票傾向
   - 確定 LLM 是否識別出了與人類評審相同的優勢和缺點
   - 評估 LLM 給出的改進建議的實用性和針對性

2. **內容質量評估**
   - 評估 LLM 摘要的準確性和完整性
   - 評估 LLM 評論中的專業性和技術洞察
   - 判斷 LLM 是否正確識別了提案的核心價值和弱點

3. **投票結果比較**
   - 計算 LLM 投票與人類投票的絕對差距 (llm_human_vote_diff)
   - 確定 LLM 投票與人類投票完全一致的百分比 (llm_agreement_pct)
   - 分析不一致的原因，特別關注 LLM 是否更傾向於給出正面或負面評價
